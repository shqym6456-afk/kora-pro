# كورة برو - النسخة الحية

خادم صغير (بدون أي مكتبات) يجلب النتائج من مزوّد بيانات ويبثها لكل المتصفحات لحظياً،
فتظهر الأهداف والتأجيلات وتغيّر المواعيد تلقائياً مع تنبيه منبثق، دون إعادة تحميل الصفحة.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. للتجربة فوراً: `node server.js` ثم افتح http://localhost:3000
   (وضع تجريبي بمباريات وهمية تتحرك بسرعة: هدف كل بضع ثوانٍ، وتأجيل، وتغيير موعد).
3. للبيانات الحقيقية: سجّل في https://www.football-data.org واحصل على مفتاح، ثم:
   `FD_TOKEN=مفتاحك node server.js`

## النشر على الإنترنت
ارفع المجلد إلى Render أو Railway أو Fly.io كخدمة Node، وأمر التشغيل `npm start`،
وأضف المتغير `FD_TOKEN`. لا حاجة لأي خطوة بناء.

## كيف يعمل
- `server.js` يجلب المباريات كل 15 ثانية وقت وجود مباراة وكل 60 ثانية خلاف ذلك، ويقارن كل دورة بالسابقة،
  فإذا تغيّرت نتيجة أو حالة أو موعد يبث تنبيهاً عبر SSE (`/api/stream`).
- تفاصيل المباراة (الأحداث والتشكيلة والإحصائيات) تُجلب عند فتحها من `/api/match/:id`.
- التشكيلة المتوقعة تُبنى من التشكيلة الأساسية لآخر مباراة منتهية لكل فريق.

## ملاحظات مهمة
- الحد المجاني للمزوّد نحو 10 طلبات في الدقيقة، والخادم يلتزم بسقف 9. للتحديث الأسرع حقاً أو لبيانات أغنى
  (تشكيلات وإحصائيات لكل مباراة) قد تحتاج خطة مدفوعة. بعض الحقول تظهر فقط حسب خطتك.
- كُتب المزوّد الحقيقي وفق وثائق football-data.org v4، ولم يُجرَّب بمفتاح فعلي في بيئة الإنشاء، فاختبره بمفتاحك وراجع السجل.
- الأخبار: تبويب «الأخبار» يعرض آخر الأحداث الحية فقط. لأخبار صحفية أضف مصدراً مرخّصاً.
- شعارات الأندية علامات تجارية، والنشر العام يحتاج ترخيصاً.
